# Triage Labels

The canonical triage roles map to these GitHub labels exactly:

| Role | Label |
| --- | --- |
| Needs triage | `needs-triage` |
| Needs info | `needs-info` |
| Ready for agent | `ready-for-agent` |
| Ready for human | `ready-for-human` |
| Won't fix | `wontfix` |

PRD issues must use both `prd` and `ready-for-agent`.

Agent-loop operational labels are managed by the setup sync script and should not be renamed manually.
